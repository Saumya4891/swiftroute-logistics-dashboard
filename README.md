# 🚚 SwiftRoute Logistics Dashboard

An interactive Power BI dashboard tracking delivery performance, driver
productivity, hub utilization and fleet health.



## 🎯 Business Problem
Management needed one view to monitor on-time delivery, customer
satisfaction and resource utilization across hubs, drivers and vehicles.

## 📊 Key Metrics
- Total Orders (with month-over-month change)
- On-Time Delivery Rate
- CSAT %
- Average Delivery Time (hrs)

## 🔍 Key Insights (December 2024)
- On-time delivery dropped to 68.2%, down 7.8% from the previous month
- Average delivery time improved by 20.8% to 34 hours
- 12 of 45 vehicles (26.7%) are in maintenance, which may limit capacity
- Several drivers have delay rates above 40% and are targets for coaching
- Hub performance varies, so capacity could be rebalanced

## 🛠️ Tools Used
Power BI · DAX · Power Query · Data Modeling

## 📁 Files
- `dashboard.pbix`: Power BI file
- `images/`: screenshots
